# ₿ Criptours - Tour Educativo por Criptomoedas

![Preview da Landing Page](.github/images/preview.png)

Landing page interativa sobre criptomoedas desenvolvida com **HTML, CSS e JavaScript puro** e focada no aprendizado prático de manipulação do DOM.

## ✨ Recursos

✔️ Explicações simples sobre BTC, ETH, ADA, XRP e Dogecoin  
✔️ Estrutura semântica e acessível (HTML5)  
✔️ Design responsivo com CSS Flexbox  
✔️ Manipulação dinâmica do DOM (JavaScript)  

## 🚧 Status do Projeto

✅ Estrutura HTML + CSS finalizada  
✅ Descrições das criptomoedas implementadas  
⏳ Integração com API de preços (opcional)
